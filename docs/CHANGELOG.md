# Changelog

## v1.1 — 2026-09-21

- Reframed Mailhub as a local personal-operations hub, with MCP as the primary interface.
- Added provider-neutral mail support: Gmail, Graph, and IMAP/SMTP.
- Added phased calendar, contacts, and tasks support using provider APIs and CalDAV/CardDAV where applicable.
- Defined local access modes, credential storage, PKCE, sending and calendar-notification safeguards, and capability-based adapters.
- Archived the previous mail-only design and reference as v1.0.

## v1.0 — archived

Original Gmail/Graph mail-only design and reference implementation. See `docs/versions/v1.0/`.
